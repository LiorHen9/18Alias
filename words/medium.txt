# 🌶️🌶️ פיקנטי: כפל משמעות
# מילה או צירוף אחד בכל שורה. שורות שמתחילות ב־# הן הערות.

# ===== הכלל: מה נכנס למשחק =====
# נכנס רק אם עונה על אחד משלושת אלה:
#  א. חפץ, אוכל או תנועה יומיומיים שהצורה או התנועה שלהם מזכירות מין או איבר
#     (למעלה ולמטה, שקע ותקע, נדנדה, בננה, רכבת נכנסת למנהרה)
#  ב. שם של מקום, דמות או סרט שהצליל או המשמעות המילולית שלו פיקנטיים
#     (גיא פינס, פתח תקווה, גבעתיים, חוף מציצים)
#  ג. מושג מיני מובהק ומוכר בעברית, שכיף להסביר במילים עוקפות
#     (ויברטור, קמה סוטרה, חשפנית)
# לא נכנס:
#  ✗ משחק מילים על מילה אחת בתוך ניב, סלנג או פתגם (דפקתי הופעה, נכנס בה, לשכב עם זה לילה, כל המרבה הרי זה משובח)
#  ✗ רומנטיקה, דייטים, גוף, לבוש וטיפוח בלי עוקץ מיני (ארוחה לאור נרות, לב שבור, חזה שעיר, ביקיני ברזילאי)
#  ✗ תרגומים וטרופים מחו"ל, ושמות שהקשר שלהם רחוק (קאוגירל, ידידות עם הטבות, השרביט של הארי פוטר, ברט וארני)
#  ✗ הריון ומשפחה (עוגה בתנור)
#  ✗ תיאורי מצבים ומשפטים שהמצאנו (מי לקח את השמיכה, הבנזין נגמר)
# המבחן הסופי: האם כשמסבירים את זה, כולם רואים תמונה וצוחקים?
