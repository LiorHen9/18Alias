# אליאס 18+

גרסה פיקנטית של אליאס, למבוגרים בלבד. אותו משחק בדיוק (טלפון אחד שעובר מיד ליד), עם שלוש רמות חריפות ובלי מצב ילדים. בכניסה הראשונה מכל מכשיר מופיע מסך אישור גיל 18+.

**הכתובת: https://alias18-liorhen9.web.app/**

האתר מתארח ב־Firebase Hosting, באתר `alias18-liorhen9` בפרויקט `alias-7214e` (אותו פרויקט של Alias ושל החדרים). כל דחיפה ל־`main` מתפרסמת שם תוך דקה או שתיים (`.github/workflows/deploy.yml`). אין שלב בנייה: הקבצים במאגר הם האתר, ו־`firebase.json` קובע אילו מהם עולים (בלי `tools/` ובלי המסמכים). אפשר לפרסם גם מהמחשב: `firebase deploy --only hosting`.

הכתובת הישנה, https://liorhen9.github.io/18Alias/, מציגה רק מסך "אליאס 18+ עבר לכתובת חדשה" (`legacy-pages/`, מתפרסם ב־`.github/workflows/legacy-pages.yml`).

## עריכת המילים

**לפני שמוסיפים מילים, קוראים את [`WORDS_GUIDE.md`](WORDS_GUIDE.md).** שם מוגדר בדיוק מה נכנס ומה לא, כולל היסטוריית משוב. אפשר לתת אותו למודל שפה יחד עם הרשימות, כדי שיסנן או ירחיב אותן. אחרי כל שינוי מריצים `python3 tools/check_words.py` כדי לוודא שלא חזרה מילה פסולה.

מילה או צירוף אחד בכל שורה. שורות שמתחילות ב־`#` הן הערות, ומילים כפולות מסוננות אוטומטית.
ב־GitHub נכנסים לקובץ, לוחצים על העיפרון ✏️, משנים ולוחצים **Commit changes**. האתר מתעדכן תוך דקה או שתיים.

## משחק בחדר

אותו מנגנון כמו במשחק המשפחתי: כל זוג משחק מהטלפון שלו, מצטרפים בסריקת QR, והזוג הבא מאשר את סיכום התור. הקוד נטען מ־`room.js` שבאתר של Alias (https://alias-liorhen9.web.app/room.js), כך שכל שיפור שם מגיע לכאן אוטומטית. בלי אינטרנט הוא לא נטען, והכפתורים של החדר מופיעים כבויים. החדרים של שני המשחקים נפרדים, וכל מי שנכנס בלינק של החדר עובר קודם את אישור הגיל. מי שיצא מהחדר בטעות רואה במסך הפתיחה כפתור "חזרה לחדר". ההסבר המלא נמצא ב־README של Alias.

## הערות

- המשחק מסומן כך שמנועי חיפוש לא יציגו אותו בתוצאות.
- אישור הגיל נשמר במכשיר, כך שלא צריך לאשר בכל כניסה.
- הנתונים של המשחק הזה נשמרים בנפרד מגרסת המשפחה, גם באותו טלפון.

## פרסום ב־Firebase Hosting (הקמה חד־פעמית)

הפריסה האוטומטית צריכה את אותו סוג מפתח שירות כמו ב־Alias (אותו פרויקט, `alias-7214e`), שמור כסוד ב־GitHub:

1. ב־Firebase ← ⚙️ ← **Project settings** ← **Service accounts** ← **Generate new private key**. יורד קובץ `.json`.
2. https://github.com/LiorHen9/18Alias/settings/secrets/actions ← **New repository secret**. שם: `FIREBASE_SERVICE_ACCOUNT`, ובתוכן מדביקים את כל הקובץ. **Add secret**.
3. מוחקים את הקובץ שירד (גם מסל המיחזור).
4. בדיקה: **Actions** ← **Deploy to Firebase Hosting** ← **Run workflow**.

ההרשאה **Firebase Hosting Admin** כבר ניתנה לחשבון השירות בזמן ההקמה של Alias.

בכל טלפון פותחים את האייקון הישן (או את הכתובת הישנה), עוברים בכפתור לכתובת החדשה, מתקינים אותה במסך הבית ומוחקים את האייקון הישן. בכתובת החדשה מאשרים שוב את הגיל. אין מה לגבות: נשמר בטלפון רק המשחק הנוכחי. אחרי שכולם עברו אפשר להפוך את המאגר לפרטי.
