# אליאס 18+

גרסה פיקנטית של אליאס, למבוגרים בלבד. אותו משחק בדיוק (טלפון אחד שעובר מיד ליד), עם שלוש רמות חריפות ובלי מצב ילדים. בכניסה הראשונה מכל מכשיר מופיע מסך אישור גיל 18+.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המשחק עצמו |
| `words/` | מאגרי המילים: `easy.txt` (🌶️ קליל), `medium.txt` (🌶️🌶️ פיקנטי), `hard.txt` (🌶️🌶️🌶️ נועז) |
| `manifest.webmanifest` | התקנה במסך הבית |
| `sw.js` | עבודה בלי אינטרנט |
| `icons/` | האייקונים |
| `WORDS_GUIDE.md` | הכללים לבחירת מילים |
| `tools/check_words.py` | בדיקה אוטומטית של הרשימות |
| `tools/review.html` | טופס אישור הביטויים (בודק המילים). עותק המקור של הדף ב־Claude; עובד רק מתוך Claude |
| `tools/apply_review.py` | מחיל את ההחלטות מהבודק על הרשימות ועל `WORDS_GUIDE.md` |

## עריכת המילים

**לפני שמוסיפים מילים, קוראים את [`WORDS_GUIDE.md`](WORDS_GUIDE.md).** שם מוגדר בדיוק מה נכנס ומה לא, כולל היסטוריית משוב. אפשר לתת אותו למודל שפה יחד עם הרשימות, כדי שיסנן או ירחיב אותן. אחרי כל שינוי מריצים `python3 tools/check_words.py` כדי לוודא שלא חזרה מילה פסולה.

מילה או צירוף אחד בכל שורה. שורות שמתחילות ב־`#` הן הערות, ומילים כפולות מסוננות אוטומטית.
ב־GitHub נכנסים לקובץ, לוחצים על העיפרון ✏️, משנים ולוחצים **Commit changes**. האתר מתעדכן תוך דקה או שתיים.

## משחק בחדר

אותו מנגנון כמו במשחק המשפחתי: כל זוג משחק מהטלפון שלו, מצטרפים בסריקת QR, והזוג הבא מאשר את סיכום התור. הקוד נטען מ־`room.js` שבמאגר Alias, כך שכל שיפור שם מגיע לכאן אוטומטית. החדרים של שני המשחקים נפרדים, וכל מי שנכנס בלינק של החדר עובר קודם את אישור הגיל. מי שיצא מהחדר בטעות רואה במסך הפתיחה כפתור "חזרה לחדר". ההסבר המלא נמצא ב־README של Alias.

## הערות

- המשחק מסומן כך שמנועי חיפוש לא יציגו אותו בתוצאות.
- אישור הגיל נשמר במכשיר, כך שלא צריך לאשר בכל כניסה.
- הנתונים של המשחק הזה נשמרים בנפרד מגרסת המשפחה, גם באותו טלפון.
